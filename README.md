# Engineering Course File Manager

A desktop academic workflow-management application for organizing engineering course files, academic regulations, faculty assignments, completion tracking, and reports.

## Portfolio Edition
This public repository is a sanitized portfolio build. It intentionally contains **no real faculty names, faculty email addresses, private credentials, internal links, or personal university records**. Synthetic staff records are used for demonstration.

## Key Features
- Admin and Faculty User workflows
- Academic structure and regulation management
- Course and elective-list management
- Faculty management and teaching assignments
- Excel/PDF teaching-distribution import workflow
- 18-item Course File checklist
- Per-course completion tracking
- Local / shared-folder workflow support
- Faculty-specific workspace
- Final reports and export workflow
- SQLite-based local data storage
- PySide6 desktop interface

## Tech Stack
Python • PySide6 • SQLite • OpenPyXL • PyMuPDF

## Run Locally
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## Privacy
Do not commit real staff names or emails, credentials, SharePoint links, drive paths, or internal university documents.
