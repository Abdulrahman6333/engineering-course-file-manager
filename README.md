# Engineering Course File Manager

A public portfolio edition of an academic workflow-management system for organizing engineering course files, faculty assignments, completion tracking, and reporting.

## Portfolio Edition
This repository is intentionally sanitized and simplified for public viewing. The working internal project remains private.

The public build contains **no real faculty names, no faculty email addresses, no private credentials, no internal links, and no personal university records**. Only synthetic demo staff data is included.

## Included in this public build
- Engineering course catalog
- Multiple academic regulations
- Synthetic faculty records
- Teaching assignments
- Dashboard statistics
- 18-item Course File checklist
- Course File completion tracking
- Faculty/course assignment overview
- Progress and status reports
- SQLite local storage
- PySide6 desktop interface

## Original project scope
The private working version also explores broader academic-management workflows such as structured curriculum management, import workflows, user roles, document/file organization, and extended reporting.

Those institution-specific parts are not copied into this public repository because the portfolio version is designed to remain privacy-safe.

## Tech Stack
Python • PySide6 • SQLite • OpenPyXL • PyMuPDF

## Run Locally
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## Privacy & Security
Do not commit real staff names, staff email addresses, credentials, internal drive links, or private institutional documents to this repository.
